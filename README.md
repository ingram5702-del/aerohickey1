# Neon Hockey (Android, Kotlin, Compose)

Упрощенная игра аэрохоккей с двумя режимами: `Vs CPU` и `2 Players`.

## Что реализовано
- Главное меню: выбор режима, `Start`, `Settings`, `Top-10`, `Exit`.
- Обновленный визуальный стиль: неоновый фон, стеклянные панели, понятный выбор режима/сложности.
- Отдельный экран `Scan QR` для сканирования QR-кодов будущих игр с сайта.
- Режимы:
  - `Vs CPU` с выбором сложности `Easy`, `Medium`, `Hard`.
  - `2 Players` на одном экране.
- Игровой экран:
  - шайба, биты, ворота, счет,
  - компактный HUD,
  - `Restart`, `Pause/Resume`, `Menu`.
- Физика:
  - отскоки от стен,
  - коллизии шайбы с битами,
  - ограничение скорости,
  - голы через центральные ворота.
- Экран результата с кнопками `Play Again` и `Main Menu`.
- Визуальные эффекты: градиент поля, трейл и тень шайбы.
- Звук и вибрация:
  - отдельный экран `Settings`,
  - переключатели `Sound On/Off`, `Vibration On/Off`.
- Обратная связь:
  - текст сообщения,
  - прикрепление фото,
  - отправка через почтовое приложение на временную почту `support@neon-hockey.example`.
- Локальный `Top-10` результатов:
  - хранится на устройстве,
  - сортировка по разнице голов (по убыванию),
  - показывает режим, счет, победителя и время матча.
- Статистика для `Vs CPU` (сохраняется между запусками):
  - лучший дифференциал счета,
  - текущая серия побед,
  - лучшая серия побед,
  - общий W/L.

## Как запустить
1. Открой проект в Android Studio (`File -> Open`).
2. Дождись Gradle Sync.
3. Запусти приложение на эмуляторе/устройстве.

## Управление
- `Vs CPU`:
  - веди пальцем в нижней половине экрана, чтобы двигать свою биту.
- `2 Players`:
  - нижний игрок (`P1`) управляет битой касанием в нижней половине,
  - верхний игрок (`P2`) управляет битой касанием в верхней половине,
  - поддерживается мультитач (оба игрока могут двигать биты одновременно).
- Цель: первым набрать 11 голов.

## QR Scanner
- Нажми `Scan QR` в главном меню.
- Разреши доступ к камере.
- Наведи камеру на QR-код. Если QR содержит ссылку, кнопка `Open` откроет её.
